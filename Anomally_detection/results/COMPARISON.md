# Edge vs board: bandwidth, closed-loop latency, accuracy, energy

Test set: the 801 replay frames (153 polyp, 648 none). Generated by `compare.py` from the receiver CSVs (`Board/receiver.py`). **Measured**: board compute, USB, edge YOLO26n, closed-loop e2e on USB, boxes. **Modelled**: BLE uplink (1300 kbit/s application throughput, 7.5 ms connection interval) and all energy (nRF54LM20 datasheet v1.0 currents × measured durations, chip only, 3.0 V; no current was measured).

## Accuracy (end to end)

| Scenario | Kvasir-SEG polyp frames with a correct box (IoU ≥ 0.5) | Polyp frames with any box | False injections (polyp-free frames with a box) |
|---|---|---|---|
| A · edge only (all frames up, YOLO26n on edge) | 92 / 100 | 149 / 153 | 8 / 648 |
| B · gated (classifier on board) | 91 / 100 | 143 / 153 | 0 / 648 |
| C · boxes on board (YOLO26-Axon) | 75 / 100 | 123 / 153 | 28 / 648 |
| C+ · classifier → YOLO26-Axon on board | 74 / 100 | 119 / 153 | 1 / 648 |
